## What to borrow

Borrow:
- hierarchy;
- density;
- layout balance;
- modularity;
- staff-profile treatment;
- scheduling patterns;
- status visibility;
- search/filter organization.

Do not borrow:
- logos;
- exact colors;
- exact card dimensions;
- artwork;
- proprietary copy;
- fake analytics;
- modules outside the actual product scope.

## Pattern summary

The best healthcare admin interfaces tend to:
1. keep the staff/doctor identity visible;
2. separate configuration concerns into focused areas;
3. avoid browser-native enterprise controls when a clearer domain control exists;
4. make scheduling and availability highly scannable;
5. use restrained healthcare colors rather than visual effects;
6. keep status and action hierarchy obvious;
7. reduce cognitive load through grouping rather than empty whitespace.
