# Hospital UI Design Skill

A reusable Codex/agent skill for designing and reviewing professional hospital and clinic interfaces.

## Recommended repository installation

Place the folder at:

```text
.agents/skills/hospital-ui-design/
```

so the repository contains:

```text
.agents/
└── skills/
    └── hospital-ui-design/
        ├── SKILL.md
        └── references/
            ├── healthcare-ui-patterns.md
            ├── doctor-editor-pattern.md
            └── visual-qa-checklist.md
```

Then ask Codex to use the `hospital-ui-design` skill for healthcare UI work.

Example:

```text
Use the hospital-ui-design skill. Review the Doctor Clinical Setup screen and redesign it without changing business logic.
```
